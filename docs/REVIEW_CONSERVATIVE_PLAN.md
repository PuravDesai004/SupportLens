# Conservative review policy protocol

The first predeclared word-support guard passed its development and previously viewed assessment gates, but a qualitative check afterward showed that the owner's illustrative question remained unflagged. Rather than use a text rule or tune a cutoff to that question, this follow-up tests a generally more cautious coverage-versus-risk target using the same saved out-of-fold predictions. The decision to investigate a stricter policy was prompted by that qualitative failure; its numerical cutoff must be selected solely from the development rows. This is exploratory iteration on data the project has already used, not a fresh independent study.

Keep the main classifier and the 0.75 scaled-score rule fixed. As in `REVIEW_GUARD_PLAN.md`, review when the main score is low **or** the matched word-only model's raw support for the main label is below a cutoff. The models share training data and are not independent reviewers. Search the fixed 0.05–0.95 grid in 0.025 steps on the 8,001 out-of-fold development rows. Select the lowest cutoff whose accepted subset has at least 1,000 examples and a 95% Wilson lower bound of at least **0.97** for accepted accuracy. This stricter development target is a conservative policy choice, not a guarantee for future questions. If no cutoff qualifies, do not promote it.

Freeze the selected cutoff before checking the previously viewed 2,002-row development assessment or the owner's example again. Promote only if, on that assessment, accepted accuracy is no worse than the current 0.75-only policy, at least 15% of its accepted errors become reviewed, at least 200 questions remain accepted, and total review is no greater than 50%. Otherwise retain the existing policy. The assessment was previously viewed in this project and affects this gate, so it is not a fresh test. Do not rescore the previously viewed official test.

Report the number of additional reviewed correct and incorrect examples, accepted accuracy and remaining accepted errors for both this and the earlier guard. The owner's question is an illustrative check after the selection; it is not a labeled benchmark, part of the threshold search, or a guarantee that other ambiguity will be detected.
